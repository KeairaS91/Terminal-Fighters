Python Boxing Game
 Description
This is a text-based boxing game built using Python.
The player fights against a computer opponent in a simple turn-based boxing match.
 How It Works
The player selects an action (punch, kick, etc.)
The computer randomly chooses its move
Health updates each round
The match continues until one fighter’s health reaches zero
 Concepts Used
Variables
If statements
While loops
User input
Random module
